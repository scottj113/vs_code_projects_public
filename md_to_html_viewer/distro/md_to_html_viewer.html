Eye Love Markdown Viewer

Drop a .md file anywhere on this window.

  • Drag & drop — drop the .md plus any local images together and the images resolve.
  • Drop a whole folder — every .md inside it becomes a list in the sidebar, so you can read straight through a project. Several .md files dropped together work the same way.
  • Paste — Ctrl+V markdown text straight onto the page.
  • Open — Ctrl+O. In Chrome/Edge this also unlocks Reload and Watch.
  • From VS Code — the Open in MD Viewer task in the project repo (Ctrl+M then ↓). The only route that can supply the file's full path.
