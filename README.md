## [Northern Lights MD Viewer](northern-lights/)

*The most powerful light Markdown viewer in the world — and an editor that keeps your
files exactly as you wrote them. One HTML file, ~270 KB, nothing to install.*

**Every other Markdown viewer renders the file. This one lets you read it.**

- **Type too small?** Scale the document 65–260%. The layout doesn't break.
- **Eyes tired?** Twelve contrast-validated palettes. Bold-all. Dark mode dims images.
- **Typo in the doc?** Click it and fix it in place. It saves to the file, and only that
  line changes — your git diff stays clean.
- **Lost in a long file?** Find and replace, tabs that survive a refresh, a contents
  sidebar, and a read-only Markdown pane while you edit.
- **Diagrams that only render on GitHub?** Mermaid works here too — offline, no
  server, no plugin. They survive into the export as SVG.
- **Need it as HTML or PDF?** One self-contained file. No toolchain, no upload.
- **Stuck with your editor's preview?** Keep the editor. **Watch** follows every save.
- **Can't install anything?** Nothing here is executable. No ticket required.

Double-click it. Drop a `.md` on it. Bookmark it.
